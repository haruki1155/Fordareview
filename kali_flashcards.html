Chapter 1

Kali Basics & VirtualBox Setup

1) What is Kali Linux, according to the lesson?

Kali Linux is presented as an open-source security package used by ethical hackers, with tools divided into categories.

Memory hook: Kali = a toolbox wearing combat boots.

2) In what forms can Kali Linux be used?

The lesson says Kali can be installed directly as an operating system, run as a virtual machine, or used as a live boot CD/USB.

Think: Full install, VM, or live traveler mode.

3) Why does the lesson recommend VirtualBox?

VirtualBox is described as useful for safe testing, especially when experimenting with unknown packages or code. It lets Kali run beside your main operating system instead of replacing it.

VirtualBox = the sandbox where chaos is allowed.

4) What is the overall installation flow you should memorize?

First install VirtualBox, then install the Kali Linux distribution, then update Kali, and finally set up another lab host for testing.

Quick order: VirtualBox → Kali → Update → Lab target

5) How do you start the VirtualBox installation process in the notes?

Download VirtualBox from its downloads page, choose the package matching your operating system, and begin the installer.

Pick the right installer first, or the setup wizard turns into a tragedy.

6) What simple click-path describes the VirtualBox install wizard?

After starting the installer, the notes walk through: Next → choose location → choose features → Yes → Install → Finish.

Mnemonic: N-L-F-Y-I-F. Not elegant. Still effective.

7) After VirtualBox is installed, how does the Kali VM setup begin?

Download the Kali package from the official website, open VirtualBox, and click New.

No VM appears by magic. Somebody has to click New.

8) What do you choose when importing Kali into VirtualBox?

You choose the correct virtual hard disk file, open it, then click Create.

Choose the right disk, or the VM will stare back at you like an empty lunchbox.

9) What are the default Kali credentials in the lesson?

Username: root
Password: toor

Mirror trick: root ↔ toor.

Updating Kali

10) Why is updating Kali important?

The notes say Kali and its tools should be kept updated to remain functional.

Outdated tools are like expired snacks: technically still there, spiritually unreliable.

11) What command refreshes package information?

apt-get update

This is the command that asks, “What’s new in the package world?”

12) What command upgrades tools and packages?

apt-get upgrade

Update checks the menu. Upgrade orders the meal.

13) What does the lesson tell you to type when asked to continue?

Type Y and press Enter.

The system asks. You give it the dramatic Y.

14) What command upgrades to a newer operating system version in the notes?

apt-get dist-upgrade

This is not a haircut. This is a whole makeover.

Chapter 2

Nmap & Zenmap

20) What is the difference between Nmap and Zenmap?

They are practically the same tool, but Nmap uses the command line while Zenmap provides a GUI.

Nmap = the brain. Zenmap = the face.

21) What is Nmap used for?

Nmap is used for network discovery and security auditing. The lesson also says it can identify hosts, services, versions, operating systems, and packet filters/firewalls.

Nmap asks the network, “Who lives here, and what are you running?”

22) Where do you open Nmap or Zenmap in Kali?

Applications → 01-Information Gathering → nmap or zenmap

The tool lives exactly where its job says it lives.

23) What does the Nmap -O option do?

It performs OS type/version detection.

nmap -O 192.168.1.101

O = OS detective mode.

24) How do you scan all TCP ports in the lesson?

Use:

nmap -p 1-65535 -T4 192.168.1.101

-p 1-65535 means all ports, and -T4 sets the scan speed used in the lesson.

25) What is a stealth scan?

A stealth scan, also called a SYN scan or half-open scan, does not complete the full TCP three-way handshake.

It knocks on the door, listens for movement, then leaves before tea is served.

26) In a SYN scan, what does SYN/ACK suggest and what does RST suggest?

SYN/ACK suggests the port is listening/open. RST suggests the port is closed or inactive.

SYN/ACK = “Come in.” RST = “Absolutely not.”

27) What command performs the SYN scan shown in the lesson?

nmap -sS -T4 192.168.1.101

-sS = sneaky SYN.

Chapter 2

Searchsploit

28) What is Searchsploit used for?

Searchsploit helps Kali users search the Exploit Database archive directly from the command line.

Searchsploit = a search engine wearing a hacker hoodie.

29) How do you access and use Searchsploit in the notes?

Open it from Applications → 08-Exploitation Tools → searchsploit and type:

searchsploit exploit index name

Chapter 2

DNS Tools

30) What is the general purpose of the DNS tools section?

The lesson says these tools help with zone transfers and domain IP resolving issues.

DNS tools are the genealogy detectives of the internet.

31) What does dnsenum.pl do?

It is a PERL script that helps retrieve MX, A, and other domain-related records.

dnsenum domain name

32) What does the lesson say DNSMAP can find?

DNSMAP helps find phone numbers, contacts, and other subdomains connected to the domain being searched.

dnsmap domain name

33) What does dnstracer do?

It determines where a given DNS server gets its information for a hostname.

dnstracer domain name

dnstracer asks DNS, “Who told you that?”

34) Which DNS command is the record collector, which is the subdomain hunter, and which is the source tracker?

dnsenum = record collector
dnsmap = subdomain hunter
dnstracer = source tracker

Enum, Map, Trace. Count it, find it, follow it.

Chapter 2

LBD Tools

35) What does LBD stand for and what does it detect?

LBD stands for Load Balancing Detector. It checks whether a domain uses DNS and/or HTTP load balancing.

LBD is traffic control for suspiciously busy servers.

36) What command is used, and what do FOUND and NOT FOUND mean?

lbd domainname

If the result is FOUND, the server has load balancing. If it says NOT FOUND, the lesson example indicates no load balance was detected.

Chapter 2

Hping3

37) Why is Hping3 considered more advanced than ping in the notes?

Because it can bypass firewall filters and work with TCP, UDP, ICMP, and RAW-IP. It also has traceroute mode and can send files through a covered channel.

Ping says hello. Hping3 arrives wearing tactical boots.

38) What are the two Hping3 command patterns shown?

hping3 -h

hping3 domain or IP -parameter

-h = meet the manual before pressing random buttons.
